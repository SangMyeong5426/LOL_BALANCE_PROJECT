# ADR 0014: 방향 출력 형식과 모델을 같은 입력으로 비교한다

- 날짜: 2026-09-21
- 상태: 채택 — 선택 실험, 서비스 예측 변경 없음
- 관계: ADR 0007의 숫자 출력과 방향·확신 출력을 비교한다. ADR 0009의
  로컬 기본 경로를 유지하며 사용자가 요청한 GPT-4.1 mini 비교를 추가한다.

## 문제와 선택

② 방향에서 설명의 결론과 `nerf_prob`가 반대인 오류가 출력 형식을 바꾸거나
모델을 교체하면 줄어드는지 확인한다. ① 대상 적중률을 개선하는 실험은 아니다.

| 후보 | 장점 | 한계 · 선택 이유 |
| --- | --- | --- |
| 기존 에이전트 루프를 네 번 실행 | 기존 B8과 가까운 실행 | 모델마다 조회 횟수·근거가 달라 출력 형식 효과와 섞인다 |
| 동일한 R1 근거를 저장하고 네 조건에 제공 | 입력을 정확히 맞추고 비용을 제한한다 | **선택.** 조회를 코드가 하므로 체인 실험이며 기존 B8과 직접 비교하지 않는다 |
| 과거 기록만 새 형식으로 변환 | 호출 비용 없음 | 새 형식이 모델의 판단에 미치는 효과를 측정할 수 없다 |

개발 표본의 앞 25건을 기본으로 사용한다. 네 조건은 qwen3.5:9b와
gpt-4.1-mini 각각의 숫자 출력·방향/확신 출력이다. 모델에 정답은 보내지 않는다.
같은 원문 근거와 지표를 주고 출력 안내와 스키마만 바꾼다. 기존 판단 기록을
덮어쓰거나 새 실험과 합치지 않는다. 입력과 설정을 고정해 재실행 때 검증한다.

정확도·AUC·기권·실패·점수 종류 수를 보고하고, 네 조건이 모두 답한 공통
표본에서 B5 다수결과 비교한다. 설명의 방향은 규칙으로 추출하지 않는다.
별도 검토 파일에 사람이 nerf/buff/unclear를 기록한 경우에만 불일치율을 낸다.
confidence=50의 방향은 명시된 direction으로 채점한다.

## 비용과 실행

OpenAI 키는 `.env`의 `OPENAI_API_KEY`에서 읽는다. 로컬만 실행하는 경로도 둔다.
이 명령의 OpenAI 호출은 누적 $1 이하로 제한하고, 호출 전 입력 UTF-8 바이트 수에
여유분을 더한 토큰 상한과 출력 1,000토큰을 예약한다. 자동 재시도는 끈다.
사용량이 반환되면 실제 토큰 단가로 정산하고, 실패·중단으로 사용량을 모르면
예약액을 유지한다. 중복 실행은 잠금으로 막는다. 다른 명령이나 다른 사용자의
API 지출은 이 로컬 장부로 제한할 수 없다.

단가: 입력 $0.40, 출력 $1.60 / 1M tokens, 캐시 할인은 적용하지 않는다.
[공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-4.1-mini)
(2026-09-21 확인). 단가가 바뀌면 실행 전에 갱신한다.

## 해석과 재검토

방향을 말로 받아도 설명과 방향의 불일치나 오판은 가능하다. 제거되는 것은
명시한 방향에서 저장 점수로 변환할 때의 반전이다. 모델 비교는 크기뿐 아니라
학습 방식 등이 함께 바뀌므로 크기만의 효과로 주장하지 않는다. 25건은 개발
진단이며 성능 전체의 증거가 아니다. 개발에서 설정을 고른 뒤 평가 표본으로
확장하려면 표본·비용·평가 횟수를 별도로 기록한다.
