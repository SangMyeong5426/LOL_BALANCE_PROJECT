# ADR 0009: 에이전트를 LangChain 으로 만들고 로컬 모델로 돌린다

- 상태: Accepted
- 날짜: 2026-09-18
- 대체: [ADR 0003](0003-llm-provider-and-calling-convention.md)의 **에이전트 조항만** —
  「예측 에이전트에는 B(Tool Runner)를 쓴다」. 추출(0003 의 A안 — `messages.parse`)은
  그대로다.

## 배경

ADR 0003 은 에이전트를 Anthropic Tool Runner 로 만들기로 해 뒀다. 그 뒤
**「API 키 없이 만든다」가 전제가 됐고**, Tool Runner 는 Anthropic 키를 전제로
했으므로 에이전트는 「키가 있어야 만든다」로 남았다([CLAUDE.md](../../CLAUDE.md) ·
[followups 21](../followups.md)).

2026-09-18, 이 저장소를 LangChain 과정 과제의 소재로 쓰면서 **저장소 밖**
(`skala-langchain`)에서 에이전트를 만들고 쟀다. 로컬 모델(Ollama 의 `qwen3.5:2b` ·
`qwen3.5:9b`)로 조회→검색→판단 루프가 **키 없이 돌았다.**

밖에 둔 것이 문제가 됐다.

| | |
| --- | --- |
| 결합 | 이 저장소의 모듈 13개를 `sys.path` 로 끌어다 썼다. 비공개 함수(`arms._retrieved`)까지다. 여기서 이름 하나를 바꾸면 저쪽이 조용히 깨지는데 여기 테스트는 모른다 |
| 기록 | 결과가 이 저장소의 문장과 어긋났다 — 「에이전트는 키가 필요하다」(CLAUDE.md · results · followups 21), 「R3 는 부르는 arm 이 없다」(용어집) |

그래서 들여온다. 들여오려면 호출 방식을 다시 정해야 한다 — 만든 것이 0003 이
D 로 기각한 LangChain 이기 때문이다.

**외부 제약이 하나 있다.** 과정 과제가 LangChain 을 요구한다. 결정에 들어간
요인이라 숨기지 않는다.

## 검토한 선택지

### A. Anthropic SDK Tool Runner — ADR 0003 그대로

- 0003 이 정한 길이고 의존성이 안 는다 — `anthropic` 은 이미 있다.
- **로컬 모델에서도 키 없이 돈다 — 확인했다(2026-09-18).** Ollama 0.33.0 이
  Anthropic 호환 `/v1/messages` 를 연다. `anthropic` 1.0.0 을 그 주소에 붙이니
  `qwen3.5:9b` 로 `messages.create` 가 `tool_use` 를 냈고, `tool_runner` 가 도구
  호출 → 답까지 루프를 끝냈다. 키 자리에는 아무 문자열이나 넣는다 — Ollama 가
  안 본다. **그래서 「키 없이」는 A 와 B 를 가르지 못한다.**
- 확인하지 않은 것 — 구조화 출력의 검증 실패를 모델에게 되돌려 다시 쓰게 하는 것,
  호출 상한, 대화 저장이 이 경로 위에서 B 처럼 도는지.
- 과정 과제 요건을 못 채운다.
- 이미 잰 구현을 다시 써야 하고, 그러면 **다시 재야 한다** — 9b 로 평가 표본을
  한 번 도는 데 한 시간이 넘는다.

### B. LangChain `create_agent` + LangGraph 체크포인터 ← **선택**

- `init_chat_model` 이 제공자를 **문자열 하나**로 바꾼다(`ollama:` · `anthropic:` ·
  `openai:`). 제공자 결정과 프레임워크 결정이 갈린다.
- **이미 만들어 쟀다.** 필요한 것이 다 들어 있다 — 도구 루프, 구조화 출력(검증에
  실패하면 모델에게 되돌려 다시 쓰게 한다), 호출 상한(미들웨어), 대화 저장(`SqliteSaver`).
- **의존성이 여섯 는다.** 전이 의존성은 훨씬 많다 — 화면(`gradio`)이 가장 크다.
- 0003 이 D 를 기각한 이유는 「**단일 변환 한 번에** 프레임워크가 과하다」였다.
  **추출**에 대한 판단이다. 에이전트는 루프·도구·구조화 출력·상한·기억을 다 쓴다.

### C. 직접 짠 루프 — Ollama API 를 바로 부른다

- 의존성이 가장 적다.
- B 가 주는 것을 **다시 짜야 한다** — 구조화 출력의 검증과 재시도, 호출 상한,
  대화 저장. 그 코드가 곧 새로 검증할 대상이 된다.
- 과정 과제 요건을 못 채운다.

서버 관리형(0003 의 C)은 같은 이유로 뺀다 — 데이터가 전부 로컬에 있다.

## 결정

**B 를 택한다.**

1. **잰 것을 그대로 들여온다.** 평가 결과([results](../results/README.md#같은-이웃으로-다시-쟀다--에이전트-b8-2026-09-18))가
   이 구현으로 나왔다. 다시 짜면 다시 재야 한다.
2. **「키 없이」 전제를 로컬 모델로 지킨다.** 기본 모델이 로컬이고, 키가 생기면
   같은 코드가 다른 제공자로 돈다.
3. **과정 과제 요건.**

**A 를 택하지 않은 이유**는 과정 요건과 재측정 비용이다. **A 도 키 없이 돈다** —
「키」는 이유가 아니다. 기술적으로는 A 가 가장 강한 대안이라 재검토 조건의 첫 줄에
둔다. **C 를 택하지 않은 이유**는 B 의 기능을 다시 짜는 일이라서다.

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 프레임워크 | `langchain` 1.4.1 · `langchain-core` 1.6.3 · `langgraph-checkpoint-sqlite` 3.1.1 | 만들고 잰 버전 |
| 제공자 통합 | `langchain-ollama` 1.1.0 **하나만** | 키 없는 길. 다른 제공자는 통합 패키지와 키를 따로 넣는다 |
| 기본 모델 | `ollama:qwen3.5:9b` — `LOL_BALANCE_AGENT_MODEL` 로 바꾼다 | 개발 표본에서 골랐다 |
| thinking | 로컬 모델은 끈다(`reasoning=False`) | `qwen3.5:2b` 한 건이 76초 → 18초 |
| 구조화 출력 | **도구 방식(`ToolStrategy`)으로 고정** | 제공자의 JSON 강제는 로컬 모델에서 도구를 하나도 안 부르고 출처를 지어냈다 |
| 안전장치 | 모델 호출 8회 · 도구 호출 12회 · 응답 한 번 600토큰 | 둘 중 하나만 있으면 다른 쪽이 샌다 — [agent](../agent.md#안전장치는-두-겹이다) |
| 화면 | `gradio` 6.27.0 | 과정 과제 |
| 토큰 추정 | `tiktoken` 0.14.0 | 키를 쓸 때의 비용 추정. 판단에는 안 쓴다 |

## 영향

- **ADR 0003** — 추출은 그대로다. 에이전트 조항에 이 문서를 가리키는 줄을 단다.
- **ADR 0001** — 의존성이 11 → 17 개가 되어 「15개를 넘으면 잠금 파일을 다시
  본다」에 닿는다. **다시 봤고, 지금은 잠그지 않는다.** 에이전트 결과의 재현은
  판단 기록을 텍스트로 두는 것([`ground_truth/agent/`](../../ground_truth/agent/README.md))으로
  잡고, 채점은 모델을 부르지 않는다. 설치가 실제로 어긋나는 일이 생기면 그때 잠근다.
- **ADR 0004** — 「에이전트 도구가 벡터 검색을 필요로 하면」에 안 닿았다. R1 k-NN ·
  R2 BM25 · R3 조회 그대로다.
- **ADR 0006** — 익명 조건을 그대로 따른다(`anon_key` · 이웃의 이름과 패치를 가림 ·
  R2 를 뺌). **오염 상한(`named`)은 로컬 모델로 재지 않았다.** 결과가 다수결에
  졌으므로, 오염이 있었다면 판단을 부풀리는 쪽이라 결론이 안 뒤집힌다.
- **ADR 0007** — 답 형식 그대로다. 「50 금지」는 스키마 검증으로 걸었다.
- **실행 시점 호출** — `run-report` 와 `score-agent` 는 여전히 0회다. 에이전트를
  새로 돌릴 때만 로컬 모델을 부른다.
- **CLAUDE.md** 의 「키가 있어야 하는 것은 에이전트 하나뿐」이 사실이 아니게 됐다.
  규칙 문서라 따로 고친다.
- **위험** — 로컬 9b 가 메모리를 약 6.6 GB 쓴다. LangChain 1.x 의 API 가 바뀔 수 있다.

## 재검토 조건

- **과정 요건이 없어지면** → A 로 옮기는 것을 다시 본다. A 가 로컬에서 도는 것은
  확인했다. 옮기면 의존성 여섯이 빠지고, 평가는 다시 돌린다.
- **화면(`gradio`)을 쓸 일이 없어지면** → 뺀다. 전이 의존성이 가장 크다.
- **설치가 재현되지 않으면** → 잠금 파일(ADR 0001).
- **LangChain 이 `create_agent`·미들웨어를 깨는 변경을 하면** → 버전을 고정한 채
  두고 다시 본다.
