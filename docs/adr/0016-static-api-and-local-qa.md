# ADR 0016: 확장은 Python 하나로 — 정적 API 와 로컬 Q&A, 서버를 두지 않는다

- 상태: Accepted
- 날짜: 2026-09-30

## 배경

세 가지 확장을 검토했다.

1. 패치별 분석 결과와 패치 노트를 넣고 「이 챔피언 너프 후에 뭐가 바뀌었나」에 근거를 붙여 답하는 기능 — 처음 제안은 Spring AI + RAG
2. 분석 결과를 조회하는 API 와 화면 — 처음 제안은 Spring
3. 새 패치가 들어오면 분석을 다시 돌리는 작업을 컨테이너로 묶어 배포 — 처음 제안은 Docker/K8s

제약은 이렇다.

| 제약 | 내용 |
| --- | --- |
| 코드 | **Python 하나다.** 계산(패널 · 효과 · 검색)과 에이전트(LangChain)가 이미 여기 있다 |
| 공개 범위 | Riot 개인 키로 모은 직접 집계는 공개용으로 쓸 수 없다([ADR 0010](0010-riot-api-direct-aggregation.md#키는)). 공개할 수 있는 u.gg 패널은 `16_13` 에서 끊겨 **더 바뀌지 않는다** |
| 검색 | 이 코퍼스에서는 BM25 가 임베딩을 이겼다 — MRR@10 0.946 대 유료 임베딩 0.488 · 로컬 임베딩 0.480([용어집](../glossary.md#밀집-임베딩이-희소를-못-이겼다)) |
| 비용 | LLM 크레딧은 반 전체가 나눠 쓴다. 공개 Q&A 는 그 크레딧을 불특정 다수에게 연다 |
| 호스팅 | 무료. 무료 상시 서버는 잠들고, 무료 DB 는 만료되거나 멈춘다 |
| 사람 | 혼자 한다. Spring 은 필수가 아니다 |

## 검토한 선택지

### A. Spring 읽기 API + PostgreSQL + Spring AI Q&A (+ Docker compose · K8s)

- 장점: 상시 서버와 DB 를 둔 흔한 구조다. Java 백엔드 경험을 보여 준다
- 단점: **같은 계산이나 LLM 층을 두 언어로 둔다.** Python 이 DB 로 내보내고 Spring 이 읽는 계약을 새로 지켜야 한다. 공개할 수 있는 자료가 바뀌지 않는데 상시 서버와 DB 를 무료로 유지해야 한다. 벡터 RAG 는 측정에서 이미 졌다. K8s 는 하루 한 번 도는 배치 하나에 비해 운영할 것이 크다

### B. FastAPI 서버 + DB, 무료 호스팅

- 장점: 같은 언어라 계산 함수를 그대로 부른다
- 단점: 공개 자료가 동결돼 있어 **서버가 하는 일이 파일을 돌려주는 것뿐이다.** 무료 호스팅의 잠들기(첫 요청 지연)와 DB 만료를 떠안는다. 최신 자료는 어차피 공개할 수 없다

### C. 정적 API + 배포 페이지 확장, Q&A 는 로컬 화면의 LangChain 에이전트를 넓힌다 ← 택함

- 장점: 서버와 DB 가 없어 비용이 0 이고, 잠들지 않고, 장애 지점이 없다. 계산은 Python 한 곳에 남는다. 공개와 로컬의 경계가 Riot 규정과 그대로 맞는다. Q&A 는 이미 있는 도구 · 자료 · 코드 대조 위에 선다
- 단점: 로그인 · 저장처럼 쓰는 기능은 못 한다. 응답은 빌드 때 고정된다. 최신 패치는 공개되지 않는다(A · B 도 마찬가지다)

## 결정

**C 를 택한다.**

- **공개**: 배포 페이지를 넓히고, 같은 자료를 `docs/site/api/v1/` 의 정적 API 로도 연다. **u.gg 패널 구간만 싣는다.** 계약 테스트가 넘는 자료를 막는다
- **로컬**: Q&A 는 로컬 화면의 LangChain 에이전트에 도구를 더해 만든다. **숫자는 도구가 계산하고, 모델은 설명만 하고, 근거는 노트 블록으로 가리키고, 코드가 대조한다.** 벡터 검색은 넣지 않는다
- **재현**: Docker 이미지 하나(선택). 자료와 키는 이미지에 넣지 않는다. **K8s 는 두지 않는다.** 매일 수집은 지금처럼 launchd 가 맡는다

A 를 택하지 않은 까닭은 같은 일을 두 언어로 하게 되고, 바뀌지 않는 자료를 위해 상시 서버와 DB 를 무료로 유지해야 하기 때문이다. B 를 택하지 않은 까닭은 서버가 파일을 돌려주는 일밖에 하지 않기 때문이다.

지킬 규칙과 단계별 완료 기준은 [`docs/extension.md`](../extension.md) 에 둔다.

## 영향

- 새 언어와 새 서버가 0 개다. 운영할 것이 늘지 않는다
- 공개 JSON 이 곧 바깥과의 계약이 된다. 깨지는 변경은 새 버전 경로로 낸다
- 최신 패치 예측과 Q&A 는 로컬 화면에서만 보여 줄 수 있다
- 후속 작업은 [`docs/extension.md`](../extension.md) 의 0~3단계다

## 재검토 조건

하나라도 생기면 다시 본다([followups 33](../followups.md)). 서버를 두게 되면 FastAPI 로 **같은 함수를 감싼다** — 계산을 옮기지 않는다.

1. Production 키를 받아 최신 자료를 공개할 수 있게 된다
2. 로그인 · 저장처럼 쓰는 기능이 필요해진다
3. Q&A 를 공개하고 그 비용을 댈 수 있게 된다
4. 벡터 검색이 `score-retrieval` 에서 BM25 를 이긴다 — 이때는 검색만 다시 본다
