# 데이터 출처 조사 (2026-08-24)

**전부 실제로 요청해서 확인한 것이다.** 검색 결과를 옮긴 것이 아니라 응답 크기와 내용을 직접 봤다. 검증 상태를 항목마다 표시했다.

## 왜 이 문서가 먼저인가

**확보할 수 없는 데이터를 전제로 쓴 계획서는 다시 써야 한다.** 그래서 데이터부터 확인했고, 실제로 그 과정에서 설계가 세 번 바뀌었다.

- 솔랭 승률이 안 잡히는 줄 알고 프로 데이터로 갈 뻔했다 → 아카이브에서 찾았다
- 한국 서버로 가려다 → 라이엇이 글로벌을 본다는 지적에 `world` 로 바꿨다
- 2016~2022 로 가려다 → 티어 체계 변경을 발견하고 2023 이후로 좁혔다

## 1. Data Dragon — 정답지 ✅ 확정

라이엇 공식. 인증 불필요.

```
버전 목록   https://ddragon.leagueoflegends.com/api/versions.json
챔피언      https://ddragon.leagueoflegends.com/cdn/{버전}/data/{로케일}/champion/{이름}.json
```

**실측**

| 버전 | Ahri.json |
| --- | --- |
| 16.16.1 (최신) | 16,823 B |
| 14.1.1 | 9,248 B |
| 12.1.1 | 8,837 B |

- **버전 550개**가 보존돼 있다 (`16.16.1` ~ `lolpatch_3.7`)
- 로케일 다국어 (`ko_KR`, `en_US` 등)
- 스킬 툴팁이 `{{ e1 }}` 형태의 변수 + `effect` 배열로 **분리 저장**된다

**용도**: 버전 간 diff 가 곧 수치 변경 내역이다. **패치 노트를 긁을 필요가 없고, 노트에 안 적히는 조용한 변경까지 잡힌다.**

## 2. u.gg 아카이브 — 솔랭 승률 ✅ 확보, ⚠️ 해독 필요

라이브 API 는 Cloudflare 가 막는다(403). **웹 아카이브를 경유하면 받아진다.**

```
원본   https://stats2.u.gg/lol/1.5/champion_ranking/{지역}/{패치}/{큐}/{티어}/1.5.0.json
경유   https://web.archive.org/web/{타임스탬프}id_/{원본 URL}
```

패치가 URL 경로에 `16_9` 형태로 들어간다.

**실측 (2026-05-08 아카이브, 패치 16_9)**: 110,991 B, JSON 파싱 성공

**형식이 두 가지다**

```
읽기 쉬운 형태 (일부 응답)
  {"win_rates":{"none":[{"win_rate":57.22,"pick_rate":2.16,"ban_rate":0,...}]}}

위치 기반 배열 (champion_ranking 다수)
  [{"adc":[["154",[[67,0,1]],1,1,17914,14505,9,12,6,146], ...
     챔피언ID ─┘        승┘ 판┘  딜┘   골드┘ K┘ D┘ A┘ CS┘   ← 추정
```

**위치 기반 배열의 필드 의미를 확정하는 것이 첫 작업이다.** 승/판 수가 있으므로 승률은 계산된다. 알려진 값과 대조하면 확인된다.

### 지역·티어 분포 (실측)

| 지역 | 아카이브 수 |
| --- | --- |
| **world** | **281** |
| euw1 | 8 |
| kr | 6 |
| na1 | 6 |
| 기타 6개 지역 | 13 |

**한국만 따로는 패치 5종뿐이라 시계열이 안 된다.** 그리고 라이엇이 글로벌을 보고 조정하므로 `world` 가 방법론적으로도 맞다.

큐: `ranked_solo_5x5` 275 · `normal_aram` 24 · `urf` 7
티어: `platinum_plus` 105 · `overall` 56 · `emerald_plus` 56

### 패치 커버리지 — world + 솔랭 + platinum_plus (실측)

**75종, 9_4 ~ 12_19**

| 연도 | 보유 | 결측 |
| --- | --- | --- |
| 2019 (9.x) | 16 | 8 |
| 2020 (10.x) | 17 | 8 |
| **2021 (11.x)** | **24** | **0 — 완전 연속** |
| 2022 (12.x) | 18 | 1 (12.15) |

2023 이후는 `emerald_plus` 로 바뀌었고 13_1 ~ 16_15 구간에 패치가 있는 것까지 확인했다. **정확한 종수와 결측은 아직 못 셌다** — 조회 시점에 아카이브가 일시 장애였다.

## 3. op.gg 아카이브 — 솔랭 승률 (한국) ✅ 파싱 확인

```
구 주소   https://web.archive.org/web/{타임스탬프}/https://www.op.gg/champion/statistics
신 주소   https://web.archive.org/web/{타임스탬프}/https://op.gg/lol/statistics/champions
```

**서버 렌더링이라 HTML 표가 그대로 파싱된다.**

```
['1', '0', 'Mordekaiser Top, Middle, Jungle', '53.62%', '12.73%']
['2', '0', 'Aatrox Top, Middle, Jungle',      '50.81%', '11.73%']
 순위  변동   챔피언 + 포지션                    승률      픽률
```

**실측 파싱 행 수**: 2018-11 → 185 · 2019-11 → 209 · 2021-11 → 215

**스냅샷 수**

| URL | 연도별 |
| --- | --- |
| 구 주소 (747개) | 2016:50 · 2017:61 · 2018:60 · **2019:274** · 2020:166 · 2021:135 · 2022:1 |
| 신 주소 (73개) | 2025:56 · 2026:17 |

2019년은 274개로 거의 매일치가 있다. **패치가 2주마다이므로 각 패치 구간에 스냅샷이 여러 개다.**

**지역: 한국(KR)로 판단된다** — 페이지의 서버 전환 목록에 `na · jp · euw · eune · oce · br · las · lan · ru · tr` 는 있는데 **`kr` 만 없다.** `www.op.gg` 가 곧 한국 서버라서다. 'KR' 9회, 'Korea' 4회, 한국어 UI 도 나온다. **정황 증거이므로 실제 수집 시 검증한다.**

**한계**: 승률·픽률만 있고 **밴율이 없다.** 2016~2017 은 구조가 달라 파서가 안 먹었다(0행).

## 4. Oracle's Elixir — 프로 경기 ✅ 2020 확인

```
https://lol.timsevenhuysen.com/gamedata/{연도}-{스플릿}/
```

**페이지가 곧 CSV 파일이다.** 링크가 아니라 본문이 CSV다.

**실측 (2020-spring, 8 MB)**

```
15,312행 · 1,276경기 · 134챔피언
패치 8종: 10.01 ~ 10.08
리그: LPL 4284 · LCK 3000 · PCS 1584 · LCS 1500 · LEC 1452 · LCS.A 1284 · CBLOL 1116 · TCL 1092
컬럼: gameid, url, league, split, date, game, patch, playerid, side, position,
      player, team, champion, ban1~ban5, gamelength, result, kills, deaths, assists, ...
```

**`patch` 컬럼이 있어 패치별 집계가 된다.** 실제로 계산해 봤다 (패치 10.06, 343경기).

```
챔피언          픽률     승률     밴율
Aphelios      35.0%   51.7%   59.5%
Senna         14.0%   60.4%   59.5%
Kalista       29.4%   60.4%   58.0%
```

**주의**: 승률이 계산된 채로 들어 있지 않다. 경기 단위 원자료이므로 **직접 집계해야 한다.**

**확보 가능 목록**: 2016-spring · 2017-complete · 2018-spring/summer/worlds · 2019-spring/summer/worlds · 2020-spring/summer

- **2020 이후는 CSV**(텍스트, 바로 파싱)
- **2019 이전은 xlsx**(바이너리) — 2017 파일 20 MB 에서 `patch` 문자열이 안 잡혔다. pandas 로 열어야 한다
- **2021~2026 은 주소를 못 찾았다.** 새 사이트(`oracleselixir.com/tools/downloads`)가 자바스크립트로 렌더링돼 링크가 안 보인다

## 5. lol.ps — 최근 패치 솔랭 ✅ 확보, 범위 좁음

```
전체 챔피언   https://lol.ps/api/statistics/tierlist.json?region=0&version={ID}&tier=2&lane={0~4 또는 -1}
챔피언 상세   https://lol.ps/api/champ/{챔피언ID}/champ-lane-features.json?region=0&version={ID}&tier=2&lane=0
일별 시계열   https://lol.ps/api/champ/{챔피언ID}/graphs.json?region=0&version={ID}&tier=2&lane=0&range=two_weeks
```

**경로에 `.json` 확장자가 붙는다** — 이것 때문에 엔드포인트 추측이 여러 번 빗나갔다.

**실측 보관 범위**

| 엔드포인트 | 내용 | 범위 |
| --- | --- | --- |
| `tierlist.json` | 승률·픽률·밴율·**표본수** | **4개 패치 (150~153)** |
| `champ-lane-features.json` | 14분 킬/데스/CS 등. **승률 없음** | 16개 패치 (138~153) |
| `graphs.json` | 일별 승률 | **14일** (`range` 다른 값은 빈 응답) |

`lane=-1` 이면 265행(챔피언×라인 전체)을 한 번에 받는다.

**용도**: 백테스트엔 부족하다. **현재 패치 실시간 예측 데모**로 쓴다.

### 버전 표기가 출처마다 다르다 — 주의

| 출처 | 같은 패치 표기 |
| --- | --- |
| lol.ps 화면 | `16.15` |
| lol.ps 내부 payload | `description:"26.15"` |
| Data Dragon | `16.16.1` (최신 기준) |

**연결 키는 이름이 아니라 `versionId` 와 `patchDate` 로 잡는다.** 이름 표기는 믿지 않는다.

## 6. 막힌 것과 이유

| 출처 | 결과 |
| --- | --- |
| u.gg 라이브 API | **403** — Cloudflare. 아카이브 경유로 우회 |
| League of Graphs | **403** |
| op.gg 라이브 | 패치 선택 기능 자체가 없음 (오늘/7일/한달) |
| lolalytics 과거 패치 | 페이지는 오는데 **데이터가 없는 껍데기**(48,836 B 동일) |
| lolalytics 아카이브 | 스냅샷 305개 있으나 **SPA 껍데기** |
| mobalytics | 403 |
| Wayback availability API | 짧은 시간에 몰아 치면 **429**. 간격을 둬야 한다 |

**아카이브가 간헐적으로 일시 장애(`Temporarily Offline`)를 낸다.** 응답이 11,832 B 로 오면 그것이다. 데이터가 없는 것과 구분해야 한다 — 실제로 한 번 오판할 뻔했다.
