# 방향 라벨을 붙이는 기준

정답지의 방향(`nerf` · `buff` · `mixed` · `adjust`)을 손으로 붙일 때 따르는 기준이다. **여러 턴에 걸쳐 붙이므로 기준이 흔들리면 그 자체가 오염원이 된다.**

도구는 [`label-material`](../../scripts/label-material) → [`save-labels`](../../scripts/save-labels) → [`score-labels`](../../scripts/score-labels).

## 네 갈래

| 라벨 | 언제 |
| --- | --- |
| `nerf` | 수치 변경이 **전부 챔피언을 약하게** 한다 |
| `buff` | 전부 강하게 한다 |
| `mixed` | **서로 다른 것**이 반대 방향으로 바뀌었다 |
| `adjust` | 조정은 됐는데 강해진 것도 약해진 것도 아니다 |

**`mixed` 는 「서로 다른 것」일 때만 쓴다.** 한 항목의 레벨별 배열이 엇갈리는 것(`10/20/30 → 5/20/40`)은 그 항목 하나를 중립으로 보고, 나머지 항목이 방향을 정한다. 그렇게 안 하면 거의 모든 챔피언이 `mixed` 가 된다.

## 버그 수정은 `adjust` 다 — 위력이 바뀌었더라도

**이 라벨이 담는 것은 「라이엇의 밸런스 의도」다.** 버그 수정에는 그 의도가 없다 — 승률이 높아서가 아니라 결함이라서 고친다.

```
❌ 「0% 치명타로 치명타가 터지던 것 수정」 → nerf   (위력은 내려갔지만 의도가 아니다)
✅ 같은 것                              → adjust
```

**한때 「실질 위력이 바뀌면 방향을 붙인다」로 적었다. 틀렸다.** 그렇게 하면 「이 챔피언이 세다고 판단했다」와 「결함을 고쳤다」가 한 라벨에 섞이고, ② 방향 예측에 순수 잡음이 된다 — 버그 수정은 승률·픽률·밴율로 예측될 리가 없다.

**되돌려서 확인했다.** 그렇게 붙인 15종을 `adjust` 로 바꾸니 손 라벨의 AUC 가 올랐다.

| 출처 | 전 | 후 |
| --- | ---: | ---: |
| 손 라벨 | 0.618 | **0.643** |
| 전체 | 0.776 | **0.784** |
| 자동 판정 | 0.825 | 0.825 |

**자동 판정이 안 변한 것이 핵심이다.** Data Dragon 은 수치 변경만 보므로 버그 수정을 애초에 안 잡는다. 자동 라벨은 처음부터 깨끗했고 **손으로 붙이면서 잡음을 넣고 있었다.**

### 그래서 이렇게 가른다

| 문구 | 라벨 |
| --- | --- |
| `Bug Fix:` · `Fixed a bug where` · `Undocumented / Bug Fix` | **`adjust`** |
| `Undocumented / Removed` — 의도가 안 적혀 있다 | **`adjust`** |
| `New Effect:` — 의도적으로 넣은 것 | 위력 방향대로 |
| `Removed:` — 의도적으로 뺀 것 | 위력 방향대로 |
| 수치 변경 | 위력 방향대로 |
| 표시기·VFX·VO·스킨 이름 | **`adjust`** |

**판단이 안 서면 `adjust` 다.** 억지로 방향을 붙이면 라벨이 잡음이 된다.

버그 수정이 승률을 실제로 움직이는지는 별개 질문이고, `evidence` 에 원문이 남아 있으므로 나중에 따로 잴 수 있다.

## 신규 출시는 라벨을 붙이지 않는다

그 패치에 처음 나온 챔피언은 **직전 버전에 존재하지 않는다.** 「너프됐나 버프
됐나」에 답할 대상이 없고, 패널에도 그 행이 없다 — 직전 패치 지표가 없어서다.

`save-labels` 가 Data Dragon 으로 판별해 **자동으로 건너뛴다.** 빠뜨린 것과는
구분된다 — 라벨을 안 붙인 챔피언을 그냥 통과시키면 어려운 것을 조용히 건너뛰게
되므로, 출시가 아닌 누락은 여전히 막는다.

```
출시라 건너뜀 1종: ['Briar']      13_18 — 그 패치에 나왔다
라벨이 빠진 챔피언 1종: [...]      ← 이건 막힌다
```

## 추천 룬 교체는 `adjust`

「Aftershock 을 Grasp 으로 대체」 같은 항목은 추천 룬 목록이 바뀐 것이지 챔피언 자체가 바뀐 게 아니다.

## 패치를 어떻게 고르는가 — **크기로 고르지 않는다**

**실제로 한 번 틀렸다.** 라벨링 부담을 줄이려고 챔피언 수가 적은 패치를 골랐더니 표본이 편향됐다.

| 표본 | n | 승률로 너프/버프 가르기 AUC |
| --- | ---: | ---: |
| 자동 판정 — 전체 52패치 | 367 | **0.804** |
| 자동 판정 — 라벨 안 한 45패치 | 322 | **0.826** |
| 자동 판정 — **내가 고른 7패치** | 45 | **0.662** |
| 손 라벨 — 같은 7패치 | 108 | 0.618 |

**같은 패치에서 자동 판정도 0.662 다.** 손 라벨이 나쁜 것이 아니라 그 패치들이 원래 그렇다. 처음에는 「Data Dragon 이 못 보는 74% 에서는 신호가 약하다」고 읽을 뻔했는데, 같은 패치 안에서 가시성으로 나눠 보니 둘 다 약했다(0.559 · 0.632). **패치 선택이 원인이다.**

패치 크기와의 관계는 단조롭지 않아 확정할 수 없다.

```
0~19종  AUC 0.725   20~29종 0.823   30~39종 0.762   40종 이상 0.887
```

**앞으로는 시드를 고정해 무작위로 뽑는다.** 크기·시대·자동 판정 비율 어느 것으로도 고르지 않는다. 편한 것을 고르면 그 편함이 결과에 들어온다.

## 채점을 어떻게 읽는가

| 판정 | 뜻 |
| --- | --- |
| `agree` | 자동 판정과 같다 |
| `extends` | 자동이 `nerf` 인데 라벨이 `mixed` — **어긋남이 아니다.** 노트에서 Data Dragon 이 못 보는 반대 방향을 더 찾았다는 뜻이다 |
| `conflict` | 자동과 반대다. **둘 중 하나가 틀렸으므로 그 자리에서 본다** |

`extends` 를 어긋남으로 세면 **라벨이 정확할수록 점수가 나빠진다.**
