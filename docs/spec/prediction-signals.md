# 예측 신호 — 무엇이 무엇을 가르는가

**과제가 둘인데 필요한 피처가 다르다.** 이 문서는 실측한 것만 적는다.

```
① 대상   다음 패치에 조정될 것인가        너프·버프가 섞인 이진 분류
② 방향   조정된다면 너프인가 버프인가      ① 을 맞힌 뒤의 문제
```

측정은 [`baseline.py`](../../src/lol_balance/baseline.py) · 패널은 [`panel.py`](../../src/lol_balance/panel.py).

## 같은 피처가 두 과제에서 반대로 움직인다

| 피처 | ① 대상 | ② 방향 |
| --- | --- | --- |
| 승률 | AUC **0.451** — 무작위보다 못하다 | AUC **0.800** |
| **\|승률 − 0.5\|** | AUC **0.567** | AUC **0.402** — 뒤집힌다 |
| 픽률 | AUC 0.548 | AUC 0.749 |
| 밴율 | — | AUC 0.772 |

**이게 이 문제의 구조다.**

- **대상**은 U자다. 강해도 약해도 조정된다. 그래서 승률로 줄 세우면 안 되고 거리로 바꿔야 한다.
- **방향**은 단조다. 강하면 너프, 약하면 버프. 그래서 승률이 바로 쓰이고, 거리는 오히려 해가 된다.

`|승률 − 0.5|` 가 방향에서 0.402 인 것은 **버프 대상이 너프 대상보다 5할에서 더 멀기 때문**이다. 라이엇은 명백히 약한 챔피언(45%)을 버프하고, 너프는 더 작은 차이(52%)에서 시작한다.

```
너프 대상 평균 승률 0.5071   ← 5할에서 +0.7%p
버프 대상 평균 승률 0.4866   ← 5할에서 −1.3%p
```

## 밴율이 승률에 거의 맞먹는다

방향 판정에서 밴율 AUC 0.772 는 승률 0.800 에 근접한다. **밴율은 「플레이어가 강하다고 느끼는가」를 담는다** — 승률에 안 잡히는 체감 강함이 여기 들어온다.

```
너프 대상 평균 밴율 0.1419   버프 대상 0.0458   3.1배
너프 대상 평균 픽률 0.0922   버프 대상 0.0516   1.8배
```

**밴 데이터가 통째로 빠진 패치(14_5)가 있다.** 0 으로 채우지 않고 결측 표시 열을 따로 둔다.

## 측정 근거와 한계

| | 표본 | 라벨 출처 |
| --- | --- | --- |
| ① 대상 | 8,767행 · 52패치 | 패치 노트 (전수) |
| ② 방향 | 너프 154 · 버프 205 | **Data Dragon 자동 판정** |

**② 의 표본은 치우쳐 있다.** Data Dragon 이 보는 것은 스탯·쿨다운·코스트·사거리뿐이고, 그것은 노트에 나온 조정의 **26%** 다. 나머지 74%인 피해량 조정에서도 같은지는 손으로 붙인 라벨이 쌓여야 안다.

파일럿 91종으로 미리 봤을 때는 승률 AUC 0.649(p=0.20)로 유의하지 않았다. **모순이 아니라 표본 부족이다** — n=19/39 에서 0.649 는 0.800 과 구분되지 않는다. 다만 그 작은 표본에서도 **밴율은 유의했다**(AUC 0.765, p=0.0055).

**방향 라벨을 늘리면 이 표가 확정된다.** 그때까지 ② 의 숫자는 자동 판정 기준임을 밝혀 둔다.
