# 게임에서 확인해야 할 항목

명세를 쓰다 확정하지 못한 것을 여기 모은다. **Phase 0-B-3 이 이 목록을 게임 데이터로 일괄 검증한다.**

임의로 채워 넣지 않는 이유는 단순하다 — 데미지 공식 하나가 틀리면 수천 판의 결과가 통째로 무의미하고, 그 사실을 알아챌 방법이 없다.

## 지금 이미 알고 있는 것

계획서가 미리 짚어 둔 항목이다. 0-A-2 를 쓰기 시작하면 위 표로 옮긴다.

- **데미지 파이프라인 순서** — 힘 가산 → 약화 → 취약 → 내림 → 블록 차감 순서가 StS1 기준이다. StS2 에서도 유효한지 확인해야 한다.
- **StS2 신규 상태이상** — Plating 등이 위 파이프라인 어디에 끼는지.
- **적 행동 패턴 로직** — 위키에 적 수치는 있으나 **어떤 조건에서 어떤 기술이 나오는지가 문서화돼 있지 않은 경우가 많다.** 이것이 없으면 페르소나의 생존 판단(2단계)이 성립하지 않는다.

**적 패턴을 끝내 못 구하면**: 확률 분기 없이 결정론적으로 순환하는 적만 골라 회피하거나, 해당 적과 20판 정도 직접 플레이하며 인텐트 순서를 기록해 역추출한다. 후자를 택하면 README 에 "위키 미기재 패턴은 플레이 로그로 역추출"이라고 명시한다 — 숨길 것이 아니라 재료다.
