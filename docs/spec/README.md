# 게임 규칙 명세

Phase 0-A 의 산출물이 모이는 곳이다. **코드를 쓰기 전 단계이고, 여기가 부실하면 이후 전 단계에서 되돌아온다.**

## 사슬에서의 위치

```text
docs/spec/  ←── 여기
     ↕
data/v0.111.0/
     ↕
src/ascent/engine/
     ↕
tests/
```

이 문서들은 **규칙이 무엇인가**를 적고, 수치가 얼마인가는 `data/` 가 적는다. 둘을 섞지 않는다 — 규칙을 코드에 하드코딩하지 않는 것과 같은 이유로, 수치를 명세 산문에 적지 않는다. 카드 12장에서 80장으로 늘릴 수 있는지가 여기서 갈린다.

**0-A-1 이 시간에 민감하다.** 패치가 나오면 실측 통계 수치가 바뀐다. v0.111.0 기준 스냅샷을 확보해야 검증 기준선이 고정된다.
