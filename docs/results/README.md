# 지금까지 보인 것

**공개 데이터만으로 라이엇의 밸런스 조정을 얼마나 설명할 수 있는가.** 2026-08-25 기준 결과다.

숫자는 전부 [`run-report`](../../scripts/run-report)가 낸 것이고 `runs/` 에 남는다. 시드 `20260824` · 시간순 분할 `15_13` 앞뒤.

## 한 줄

**「어느 쪽으로 조정할까」는 잘 맞고, 「누구를 조정할까」는 잘 안 맞는다.**

```
② 방향  너프냐 버프냐    AUC 0.841 · 정확도 80.7%     ← 규칙으로 잡힌다
① 대상  누가 조정되나    R-정확도 25.6% (기준선 14.5%)  ← 잘 안 잡힌다
③ 효과  조정이 먹혔나    80% 가 의도한 방향으로 갔다
```

## ① 대상 — 누가 조정되나

패치 안에서 챔피언 약 172종을 줄 세우고, 실제 조정된 수만큼 뽑아 맞힌 비율을 본다. 평가 20패치 · 3,433행 · 기준선 **14.5%**.

| arm | 방법 | R-정확도 | P@10 | AUC |
| --- | --- | ---: | ---: | ---: |
| A0 | 무작위 | 14.3% | 16.0% | 0.498 |
| A0b | 픽률 높은 순 | 20.5% | 24.5% | 0.548 |
| A0c | 승률 높은 순 | 15.2% | 16.0% | **0.451** |
| A0d | \|승률 − 0.5\| 큰 순 | 20.9% | 28.0% | 0.567 |
| **A1** | **로지스틱 회귀 — 수준** | **25.6%** | 30.0% | 0.590 |
| A2 | 로지스틱 회귀 — 수준 + 추세 | 25.5% | 31.0% | 0.596 |
| A3 | 유사 사례 50개 (k-NN) | 24.1% | 29.5% | **0.613** |
| A4 | 규칙 엔진 (LLM 제안) | 22.5% | **31.0%** | 0.552 |

**최고가 기준선의 1.8배다.** 절대값이 25.6% 라는 것은 **넷 중 셋은 못 맞힌다**는 뜻이다.

**승률 순(A0c)이 무작위보다 나쁘다**(AUC 0.451). 조정되는 쪽이 양 끝이라 단조롭지 않다. 거리로 바꾸면(A0d) 0.567 로 뒤집힌다.

## ② 방향 — 너프냐 버프냐

조정된 챔피언만 본다. 평가 135건 · 기준선 51.9%.

| arm | 방법 | AUC | 정확도 |
| --- | --- | ---: | ---: |
| B0 | 무작위 | 0.510 | 51.9% |
| B0b | 승률 높은 순 | 0.836 | — |
| B0c | 밴율 높은 순 | 0.737 | — |
| B0d | 픽률 높은 순 | 0.726 | — |
| B1 | 로지스틱 회귀 — 수준 | 0.759 | 70.4% |
| B2 | 로지스틱 회귀 — 수준 + 추세 | 0.778 | 71.9% |

**다섯 건 중 하나는 의도한 방향으로 안 간다.**

## 어디까지 되고 어디부터 안 되나

증명 대상 4번 — **이것이 가장 정직한 결과다.**

| 단계 | 질문 | 성적 | 판정 |
| --- | --- | --- | --- |
| 1 · 대상 | 누가 | 25.6% (기준선 14.5%) | **약하다** |
| 2 · 방향 | 너프냐 버프냐 | 80.7% (기준선 51.9%) | **된다** |
| 3 · 항목 | 무엇을 | — | **아직 안 함** |
| 4 · 폭 | 얼마나 | — | **아직 안 함** |

그리고 방향 안에서도 갈린다.

```
nerf · buff 만              정확도 69.6%   (기준선 50.0%)
+ mixed                          49.4%          33.3%
+ mixed + adjust                 37.2%          25.0%
```

**`mixed` 는 24건 중 1건만 맞힌다** — 현재 통계로 사실상 예측되지 않는다. 조정된 챔피언의 15%가 여기 속한다.

### 「LLM arm」이 무슨 뜻인가 — 오해하기 쉽다

`A4` · `B4` 가 「LLM」으로 표시돼 있지만 **실행할 때 API 를 부르지 않는다.**

| | |
| --- | --- |
| 규칙 8개 | **대화 중 Claude 가 학습 32패치를 읽고 제안**했고 `rules/proposed.jsonl` 에 텍스트로 있다 |
| 방향 라벨 242종 | **대화 중 Claude 가 패치 노트를 읽고** 붙였다 |
| 실행 시점 | 그 텍스트를 읽어 **채점만** 한다 |

**`ANTHROPIC_API_KEY` 를 쓴 적이 한 번도 없다.** `extract.py`(수치 추출)는 코드와 테스트만 있고 돌린 적이 없으며, RAG 검색기와 에이전트는 **코드가 아예 없다.**

즉 **돌아가는 LLM 시스템은 아직 없고**, 지금 보인 것은 「모델이 낸 규칙을 코드가 채점하면 통계 베이스라인과 견줄 만한가」까지다. 자세한 것은 [ground_truth/README](../../ground_truth/README.md).

**검색기 셋(R1·R2·R3)은 만들어졌다** — [`retrieval.py`](../../src/lol_balance/retrieval.py). 에이전트가 쥘 도구이고, 검색만이라 API 키가 필요 없다. 다만 **그것을 쥐고 판단하는 루프가 아직 없다.**

## 이 문서가 말하지 않는 것

- ❌ 우리가 라이엇보다 밸런스를 잘 잡는다
- ❌ 예측이 정확하다 — **정확도는 측정 대상이지 전제가 아니다**
- ❌ 라이엇의 내부 프로세스가 이렇다 — **관측된 패턴**일 뿐이다
- ❌ 조정이 옳았다·틀렸다 — 효과를 **측정**하는 것이지 판정이 아니다
