## 왜 접었나

**게임을 재구현해야 해서 AI 부분에 도달하기 전에 무너질 구조였다.**

대화가 진행되면서 범위가 계속 늘었다 — 1막 한 갈래에서 두 갈래로, 카드 12장에서 전체 풀로, 덱 고정에서 AI 드래프트로, 1막에서 3막까지로. 하나하나 타당한 확장이었고 대부분 도메인 지식에서 나온 정당한 지적이었다. 그러나 합치면 룰 엔진·카드 70장·적 30종·보스 9종·유물·포션·이벤트를 만드는 일이 됐다.

**그리고 현업 조사가 이 방향이 틀렸다는 것을 보여줬다.** 게임 업계에서 생성형 AI 사용의 81%가 리서치·검수이고 창작은 19%다. 게임을 재구현하는 방식은 현업 어디에도 없다.

## 여기서 얻은 것 — 새 주제에 그대로 쓴다

1. **외부 정답지가 있는 주제를 고른다.** 자기가 만든 것을 자기가 평가하는 순환을 피한다. 이 프로젝트에서 가장 값졌던 아이디어가 「개발사가 이후 실제로 조정한 것과 대조한다」였고, 새 주제가 그것을 그대로 쓴다.

2. **범위를 먼저 못 박는다.** 좋은 아이디어는 계속 나온다. 자르는 규율이 없으면 끝나지 않는다.

3. **가장 불확실한 것부터 재본다.** 이 프로젝트는 데이터 확보 가능성을 확인하기 전에 계획서를 두 번 썼다. 새 주제에서는 데이터부터 확인했고, 실제로 설계가 세 번 바뀌었다.

4. **미확정 항목을 목록으로 관리한다.** 임의로 채우면 조용히 오염된다.

5. **AI 를 어디에 쓰고 어디에 안 쓰는지 가른다.** 결정론적 로직과 LLM 의 경계를 명시하는 습관.
