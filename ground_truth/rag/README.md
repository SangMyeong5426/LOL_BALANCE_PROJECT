# 검색 위의 판단 — arm `B6` 의 재료

**`A5`·`B5` 는 이웃 라벨을 다수결할 뿐 생성 단계가 없다.** 여기가 그 위에 판단을
올리는 자리다. 근거는 [ADR 0006](../../docs/adr/0006-rag-generation-and-contamination-control.md).

## 만드는 법

```bash
./scripts/make-rag-context --condition anon             # 평가 전량 234건
./scripts/make-rag-context --condition named --limit 80 # 오염 상한 80건
```

맥락은 `runs/` 에 나온다(커밋하지 않는다). 그것을 읽고 대화에서 판단해 여기에
`*.jsonl` 로 저장한다.

```jsonl
{"key": "834b7a", "condition": "anon", "nerf_prob": 78, "reason": "승률 51.6%에 상승 추세, 이웃 6종 중 5종이 너프"}
```

| 필드 | |
| --- | --- |
| `key` | 익명 키. **챔피언 이름을 담지 않는다** |
| `condition` | `anon`(본 조건) 또는 `named`(오염 상한) |
| `nerf_prob` | **너프일 확률 0~100 정수.** 라벨이 아니라 점수여야 AUC 를 잰다 |
| `reason` | 판단 근거. **비워 두면 읽을 때 막힌다** |

## 왜 익명인가

**방향 라벨 1,599종을 대화 안의 Claude 가 붙였고, 그 라벨이 곧 채점 정답이다.**
「기억 안 난다」고 주장해도 저장소가 검증할 수 없다.

```
구조   대상을 익명으로 준다 — 이름을 모르면 기억을 꺼낼 열쇠가 없다
측정   이름만 주는 조건(named)을 따로 돌려 찍기를 넘는지 본다
```

**`named` 가 찍기(AUC 0.5)를 뚜렷이 넘으면 `anon` 결과를 버린다.** 그 기준을
결과를 보기 전에 정해 둔다 — 보고 나서 정하면 그것이 p-해킹이다.

## 판단할 때 열지 않는 것

`runs/*.key.jsonl` 은 익명 키를 챔피언·패치·정답에 잇는 대조표다. **채점할 때만
쓴다.**


## 커버리지 — **229 / 239 (2026-08-27)**

핫픽스 라벨 44종을 붙이며 ② 평가 구간이 235 → 239 종이 됐고, 늘어난 행에는
판단이 없다. **새로 만들지 않는다** — 그 행들의 정답을 이미 본 뒤라 오염된다.

대신 `B5` 를 같은 229종으로 잘라 `B5s` 로 함께 낸다. 표본이 다르면 짝지어 비교가
안 되기 때문이다.


## 형식 — **심지는 필수, 나머지는 선택**

[ADR 0007](../../docs/adr/0007-answer-schema.md)이 정했다.

```jsonl
{"key": "834b7a", "condition": "anon", "nerf_prob": 78, "reason": "…",
 "as_of": "16_13", "abstain": false, "adjust_prob": 62,
 "evidence": [{"source": "R1", "text": "이웃 25종 중 너프 24"}],
 "warnings": [{"kind": "missing_data", "text": "이 패치에 프로 픽·밴이 없다"}]}
```

| 칸 | 필수 | 무엇 |
| --- | :---: | --- |
| `key` · `condition` · `nerf_prob` · `reason` | **예** | `B6` 이 채점하는 부분 |
| `as_of` | 아니오 | 검색 경계. 나중에 그 답을 의심할 때 되짚는다 |
| `abstain` | 아니오 | 판단할 재료가 없으면 참 |
| `adjust_prob` | 아니오 | **arm 이 없다** — 에이전트가 한 건씩 답할 때 쓴다 |
| `evidence[]` | 아니오 | `source` 는 `R1`·`R2`·`R3`·`규칙`·`수치` |
| `warnings[]` | 아니오 | `kind` 는 자유, `text` 는 필수 |

**여기 있는 314건은 필수 칸만 채워져 있고 그대로 유효하다.** 새 칸을 필수로
만들면 전부 다시 만들어야 하고, 그것만 여덟 묶음이 걸렸다.

**`read_judgments` 가 형식을 그 자리에서 거절한다.** `abstain: "false"` 처럼
비지 않은 문자열이 참으로 새는 것까지 막는다 — 314건을 다 만든 뒤에 알면 늦다.
