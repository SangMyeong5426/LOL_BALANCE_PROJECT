# 후속 질문(Q&A)의 고정 질문과 받은 답

[extension 2단계](../../docs/extension.md)의 완료 기준을 재는 자료다.

> 학습 구간에서 고른 고정 질문 20~30개에서 도구에 없는 숫자 0개, 없는 노트 블록 0개

```bash
./scripts/score-qa             # 여기 있는 답 전부를 다시 대조한다 — 모델을 안 부른다
./scripts/score-qa --detail    # ⚠ · ⚪ 가 붙은 답을 하나씩 보인다
```

`B6` · `B8` 의 판단을 글로 두고 채점만 다시 하는 것과 같은 방식이다. 답을 한 번 받아 두면
**대조 규칙을 고쳐도 모델을 다시 돌리지 않는다.** 기록에 코드가 만든 맥락과 도구 출력이
다 들어 있어 `data/` 도 필요 없다.

## 파일

| 파일 | 무엇 | 지시 지문 |
| --- | --- | --- |
| `questions-dev-v1.jsonl` | 고정 질문 27개. **대조 규칙과 답 형식을 고칠 때 본 질문이다** | |
| `answers-dev-v1-ollama-qwen3.5-9b.jsonl` | 처음 받은 답 — 답 형식 설명에 진짜 절 이름을 예로 들었다 | 없음(지문을 적기 전) |
| `answers-dev-v1-ollama-qwen3.5-9b-r2.jsonl` | 그 예시를 뺐다 — **지금 실린 지시다** | `a1303f76` |
| `answers-dev-v1-ollama-qwen3.5-9b-r3.jsonl` | 가짜임이 분명한 예시(`Q - 스킬 이름`)로 바꿨다 | `776fa487` |
| `questions-dev-v2.jsonl` | 씨앗을 옮겨 만든 다른 질문 27개. 고칠 때 본 적 없는 질문이다 | |
| `answers-dev-v2-ollama-qwen3.5-9b.jsonl` | 가짜 예시를 둔 채 **한 번** 받은 답 — 이것을 보고 예시를 뺐다 | `776fa487` |
| `questions-dev-v3.jsonl` | 씨앗을 한 번 더 옮긴 질문 27개(1개는 `dev-v2` 와 겹친다) | |
| `answers-dev-v3-ollama-qwen3.5-9b.jsonl` | 지금 실린 지시로 **한 번** 받은 답. 이 뒤로는 아무것도 고치지 않았다 | `a1303f76` |

**질문과 답은 덮어쓰지 않는다.** 고치려면 새 이름으로 만든다.

**지시 지문**은 모델이 받는 지시(프롬프트 · 답 형식 · 도구 설명)를 해시한 앞 8자다. 설명의
예시 하나에 답이 바뀌었다 — 어떤 지시로 받은 답인지 모르면 견줄 수 없다. `run-qa` 는 지문이
다른 답이 있는 파일에 이어 적지 않고, 지금 실린 지시가 `-r2` 의 지문과 다르면
`tests/test_agent_qa_set.py` 가 깨진다.

**어느 것을 보고 무엇을 고쳤나.** `dev-v1` 의 답을 보며 대조 규칙과 답 형식을 고쳤다. 그것을
커밋으로 굳히고 `dev-v2` 를 물었더니 가짜 예시가 틀린 선택으로 드러나 예시를 뺐다(대조
규칙은 그대로 뒀다). 다시 굳히고 `dev-v3` 을 물었다. **`dev-v3` 이 지금 상태를 처음 보는
질문으로 잰 유일한 값이다.**

`r2` 를 받기 전에 설명을 길게 고친 지시로 9건을 받다가 멈춘 것이 있다(패치를 `[14_9]` 로
적었다). 다 돌지 않아 여기 두지 않았다.

## 질문

기준 패치는 학습 구간의 끝(`15_13`)이다. **평가 구간에 서서 묻는 질문은 만들지 않는다** —
프롬프트와 대조 규칙을 고칠 때 이 질문들을 보기 때문이다. 씨앗은 설정의 `seed`(`dev-v2` 는
거기에 1, `dev-v3` 은 2 를 더한 것)라 다시 만들어도 같다.

| 종류 | 수 | 무엇을 보나 |
| --- | ---: | --- |
| `effect` | 8 | 너프 · 버프된 조정의 전후. 표본이 얇은 것 4 · 두꺼운 것 4 |
| `mixed` | 2 | 방향이 갈린 조정 — 「의도한 방향」을 말하면 안 된다 |
| `unadjusted` | 2 | 그 패치에 조정되지 않았다 — 도구가 거절한다 |
| `gap` | 2 | 직전 패치 지표가 없다 — 도구가 거절한다 |
| `notes` | 5 | 그 패치 노트에 이 챔피언의 절이 있다 |
| `stats` | 3 | 최근 지표의 흐름 |
| `cases` | 2 | 닮은 사례 |
| `beyond` | 3 | 기준 패치 **뒤**를 묻는다 — 「볼 수 없다」고 답해야 한다 |

**거절해야 하는 질문 7개를 일부러 넣었다.** 잴 수 있는 것만 물으면 「없는 것을 지어내는가」를
못 본다. 질문이 의도한 경우를 실제로 만드는지는 테스트가 도구에 물어 확인한다.

## 만드는 법

```bash
./scripts/make-qa-questions dev-v1                    # 질문 — 있는 이름은 덮어쓰지 않는다
./scripts/make-qa-questions dev-v4 --seed-offset 3    # 씨앗을 옮긴 다른 질문
./scripts/run-qa dev-v1                               # 로컬 모델(키 없음 · 비용 0) → runs/
./scripts/run-qa dev-v1 --label r4                    # 지시를 고쳤으면 새 이름에 받는다
cp runs/qa-dev-v1-ollama-qwen3.5-9b.jsonl ground_truth/qa/answers-dev-v1-ollama-qwen3.5-9b.jsonl
```

**다 돈 것만 옮긴다.** `run-qa` 는 이어받으므로 `runs/` 의 기록은 중간일 수 있다. 27개에
8~10분 걸린다. 유료 모델은 `--model` 로 적어야 돌고, 이 실험의 누적 상한 $1 에 닿으면 묻기
전에 멈춘다. **여기 있는 답은 전부 로컬 모델이다 — 유료 호출은 없었다.**

## 읽는 법

**✅ 는 「맞는 답」이 아니다.** 답의 숫자와 인용이 출처(도구 출력 · 코드가 만든 맥락 ·
질문)에 있다는 뜻이다. 숫자의 뜻을 틀리게 쓴 것은 못 잡는다
([agent.md](../../docs/agent.md#후속-답도-코드가-대조한다-2026-10-01)).

**거절해야 하는 질문은 ⚪ 가 가장 좋은 답이다.** 「볼 수 없습니다」에는 대조할 숫자도 인용도
없다. 그 질문에서 ⚠ 는 거절을 「없었다」로 옮겼거나 인용 칸에 없는 것을 적었다는 뜻이다.

수치와 거기서 배운 것은 [agent.md](../../docs/agent.md#고정-질문-27개로-쟀다-2026-10-01)에 있다.

기록의 도구 출력에 든 패치 노트 문장은 위키 전사본에서 왔다
([data-sources](../../docs/spec/data-sources.md) — CC BY-SA 3.0,
[extension 2절 9항](../../docs/extension.md)). 직접 집계(`16_16` 뒤)에서 나온 값은 없다 —
기준 패치가 `15_13` 이라 도구가 그 뒤를 보지 않는다.
